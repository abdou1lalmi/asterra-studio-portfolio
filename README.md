# Asterra Studio Portfolio

A premium portfolio concept for a product and brand studio serving ambitious teams. The experience is designed as an **architectural editorial journal**: asymmetric composition, restrained typography, high-contrast material cues, and measured motion that supports the work instead of competing with it.

> Products worth choosing need a world worth entering.

## What this project demonstrates

| Focus | Implementation intent |
| --- | --- |
| **Art direction** | A calm, exacting visual language built around bone paper, obsidian ink, graphite, and a single signal colour. |
| **Editorial layout** | Asymmetric narrative composition, preserved negative space, image captions, counters, and case-study-first storytelling. |
| **Interaction design** | Clear hover states, keyboard-visible focus, purposeful transitions, and reduced-motion support. |
| **Frontend craft** | Reusable React components, responsive behaviour, semantic structure, and a deliberate typographic system. |

## Design principles

The interface treats a studio portfolio like a crafted publication: **case studies are the evidence layer**, services provide context, and every interaction has a clear destination. The visual system uses measured motion rather than scroll-jacking or decorative loops, while the signature chartreuse accent is reserved for high-value annotations and calls to action.
